### Setting environment variables

1. Edit the `~/.zshrc` file
```bash
nano ~/.zshrc
```
2. Add authentication, this have been shared at some point...
```bash
export USER02466="<Username>"
export PASS02466="<Password>"
```

```bash
nano ~/.bashrc
```
